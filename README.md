TruthGuard — AI Fraud & Misinformation Detector

TruthGuard is an AI-powered platform that helps users identify fake news, job scams, phishing attempts, financial fraud, medical misinformation, and AI-generated media.

It combines Google Gemini, Firebase, Google Safe Browsing, and machine learning to analyze suspicious content and provide clear risk assessments.

Features
Fake News Detection

Analyzes news and claims and classifies them as:

Real / Likely Reliable
Suspicious
Likely Fake / Misleading

Supports text, images, and video.

Job Scam Detection

Identifies suspicious job offers based on:

Unrealistic salaries
Payment requests
Fake recruitment
Suspicious contact information
Urgent requests
Requests for sensitive information
Phishing Detection

Analyzes URLs for:

Phishing websites
Suspicious domains
Malicious URLs
Fake login pages
Impersonation websites
Financial Fraud Detection

Identifies potential:

Banking scams
Investment scams
UPI/payment fraud
Fake payment requests
Lottery and prize scams
Impersonation scams
Medical Misinformation Detection

Analyzes health-related claims for potentially misleading or unsupported information.

AI-Generated Media Analysis

Analyzes supported images and media for potential signs of AI generation or manipulation.

Multimodal Analysis

Supports:

Text
Images
Video
URLs

Technology Stack:
Google Gemini / Google GenAI — AI-powered content analysis and reasoning
Firebase Authentication — User authentication
React + Vite — Frontend development
JavaScript / TypeScript — Application development
HTML & CSS — User interface and responsive design
